## 2. 機能詳細 / Function Details

### 2.1 認証・セッション管理 / Authentication

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-AUTH-01 | メールアドレスとパスワードによるログイン | 高 |
| FR-AUTH-02 | ログイン成功時に HTTP-only Session Cookie を発行し、セッションを維持する | 高 |
| FR-AUTH-03 | ログイン時にユーザープロフィールを Firestore `users` コレクションへ自動同期する | 高 |
| FR-AUTH-04 | ログアウト時に Session Cookie を削除し、ログイン画面へリダイレクトする | 高 |
| FR-AUTH-05 | 有効なセッションを持たないユーザーは保護されたルートへアクセスできない | 高 |

---

### 2.2 チャット / Chat

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-CHAT-01 | テキストメッセージをリアルタイムで送受信できる | 高 |
| FR-CHAT-02 | チャンネルは「パブリック」「プライベート」「DM」の3種類をサポートする | 高 |
| FR-CHAT-03 | メッセージへの返信（スレッド形式）ができる | 中 |
| FR-CHAT-04 | メッセージに絵文字リアクションを付けることができる | 低 |
| FR-CHAT-05 | 既読状態を管理し、未読件数をバッジ表示する | 高 |
| FR-CHAT-06 | 過去のメッセージを無限スクロールで追加読み込みできる | 中 |
| FR-CHAT-07 | Admin はチャンネルの作成・編集・削除、およびプライベートチャンネルのメンバー管理ができる | 高 |
| FR-CHAT-08 | 社員名簿からメッセージを送ると、DM チャンネルが自動生成される | 高 |

---

### 2.3 お知らせ / Announcements

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-ANN-01 | Admin はタイトル・本文・種別（info / warning / success / event）・画像を指定してお知らせを投稿できる | 高 |
| FR-ANN-02 | Admin は重要なお知らせをピン留めし、一覧の先頭に表示できる | 高 |
| FR-ANN-03 | 一覧はピン留め優先・新着順で表示される | 高 |
| FR-ANN-04 | 従業員はお知らせにリアクションおよびコメントができる | 中 |
| FR-ANN-05 | 注目のお知らせはホーム画面にBento レイアウトで表示される | 中 |
| FR-ANN-06 | アンカーURL（`#announcement-{id}`）で特定のお知らせに直接アクセスできる | 低 |
| FR-ANN-07 | 種別が `event` のお知らせは、全社カレンダーに自動連携される | 中 |

---

### 2.4 カレンダー / Calendar

| ID | 要件 | 優先度 |
|----|------|--------|
| FR-CAL-01 | イベントのタイトル・開始/終了日時・説明・種別を設定して作成できる | 高 |
| FR-CAL-02 | イベントの公開範囲は「全社」「グループ」「個人」の3種類から選択できる | 高 |
| FR-CAL-03 | 個人イベントは作成者のみ、グループイベントはそのグループのメンバーのみ閲覧できる | 高 |
| FR-CAL-04 | イベントの編集・削除は作成者または Admin のみが行える | 高 |
| FR-CAL-05 | 月・週・日・アジェンダの4種類の表示モードをサポートする | 中 |
| FR-CAL-06 | 種別・公開範囲によるイベントの検索・フィルタリングができる | 中 |
| FR-CAL-07 | サイドバーのミニカレンダーとメインカレンダーの表示日付を同期する | 低 |

## 3. 受け入れ基準 / Acceptance Criteria

| # | 基準 | 確認方法 |
|---|------|---------|
| AC-01 | ログイン後、全モジュールに 5秒以内にアクセスできる | 手動テスト / E2E テスト |
| AC-02 | チャットメッセージが送信後 1秒以内に受信側に表示される | 2アカウントによるリアルタイムテスト |
| AC-03 | ピン留めされたお知らせが一覧・ホーム画面の先頭に表示される | 手動テスト |
| AC-04 | グループ A に属さない従業員がグループ A のイベント・ドキュメントを閲覧できない | 権限テスト |
| AC-05 | Admin がロールを変更後、次回リロード時に変更が反映される | 手動テスト |
| AC-06 | ナレッジベース記事が Markdown 形式で正しくレンダリングされる | 各種コンテンツでの手動テスト |
| AC-07 | 768px 以上の画面幅で正常に表示・操作できる | Desktop・Tablet での表示確認 |
| AC-08 | セッション情報・Admin 認証情報がクライアントに漏洩しない | コードレビュー + セキュリティ確認 |
