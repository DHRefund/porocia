| ID | Yêu cầu | Độ ưu tiên |

## 3. Tiêu chí Chấp nhận / 受け入れ基準

| # | Tiêu chí | Phương pháp kiểm tra |
|---|----------|---------------------|

| AC-02 | Tin nhắn chat xuất hiện ở phía nhận trong vòng 1 giây sau khi gửi | Kiểm thử thời gian thực với 2 tài khoản |
| AC-03 | Thông báo được ghim hiển thị ở đầu danh sách trên cả trang thông báo lẫn trang chủ | Kiểm thử tay |
| AC-04 | Nhân viên không thuộc nhóm A không thể xem sự kiện hoặc tài liệu có phạm vi nhóm A | Kiểm thử phân quyền |
| AC-05 | Sau khi Admin thay đổi vai trò thành viên, thay đổi có hiệu lực ngay ở lần làm mới tiếp theo | Kiểm thử tay |
| AC-06 | Bài viết Knowledge Base hiển thị đúng định dạng Markdown với các loại nội dung khác nhau | Kiểm thử tay |
| AC-07 | Giao diện hiển thị đúng và sử dụng được trên màn hình từ 768px trở lên | Kiểm thử responsive trên Desktop & Tablet |
| AC-08 | Toàn bộ dữ liệu nhạy cảm (session, thông tin xác thực admin) không bị lộ ra phía client | Code review + Kiểm tra bảo mật |

## 4. Lộ trình Phát triển / 開発ロードマップ

### Giai đoạn 1 — MVP ✅ (Đã hoàn thành)
Xác thực / Chat cơ bản (Channels + DM) / Thông báo / Lịch / Thư mục nhân sự / Knowledge Base cơ bản / Hồ sơ cá nhân / Admin Dashboard cơ bản

### Giai đoạn 2 — Củng cố (Đang phát triển)
Hoàn thiện Firestore Security Rules / Quản lý sự kiện trong Admin Dashboard / Màn hình cài đặt hệ thống / Tối ưu hiệu năng & UX

### Giai đoạn 3 — Mở rộng (Kế hoạch)
Push Notifications & Email Reminders / Kéo & Thả lịch / Tích hợp dịch vụ bên thứ ba / Báo cáo & Phân tích nâng cao / Ứng dụng di động
