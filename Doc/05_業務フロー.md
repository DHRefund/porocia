# 業務フロー一覧 (Porocia Portal)

本書は、**Porocia** ポータルシステムの主要な業務フローをまとめたものです。  
各フローは、利用者の操作とシステムの応答を中心に記載しています。

---

## 1. ログインフロー

社員がシステムにログインし、ホーム画面にアクセスするまでの流れを示します。

```mermaid
sequenceDiagram
    autonumber
    actor User as 社員
    participant System as システム

    User->>System: メールアドレスとパスワードを入力し「ログイン」をクリック
    System->>System: 認証情報を検証
    alt 認証成功
        System-->>User: ホーム画面（ダッシュボード）を表示
    else 認証失敗
        System-->>User: エラーメッセージを表示（「メールアドレスまたはパスワードが正しくありません」）
    end
```

---

## 2. ページアクセス制御フロー

ログイン済みユーザーと未ログインユーザーがページにアクセスした際の振り分けを示します。

```mermaid
sequenceDiagram
    autonumber
    actor User as 利用者
    participant System as システム

    User->>System: ページにアクセス
    System->>System: ログイン状態を確認
    alt ログイン済み
        System-->>User: 要求されたページを表示
    else 未ログイン
        System-->>User: ログイン画面へ自動リダイレクト
    end
```

---

## 3. チャット（メッセージ送信）フロー

社員同士がチャット機能を利用してメッセージをやり取りする流れを示します。

```mermaid
sequenceDiagram
    autonumber
    actor UserA as 送信者
    participant System as システム
    actor UserB as 受信者

    UserA->>System: メッセージを入力し「送信」をクリック
    System->>System: メッセージを保存
    System-->>UserA: 送信済みメッセージをチャット画面に表示

    alt 受信者がチャット画面を開いている場合
        System-->>UserB: 新しいメッセージをリアルタイムで表示
    else 受信者が別の画面にいる場合
        System-->>UserB: チャネル一覧に未読バッジ（件数）を表示
    end

    Note over UserB: 受信者がチャット画面を開くと、未読バッジは自動的にクリアされます
```

---

## 4. ダイレクトメッセージ（1対1チャット）開始フロー

社員名簿から特定の相手を選び、1対1のチャットを開始する流れを示します。

```mermaid
sequenceDiagram
    autonumber
    actor UserA as 利用者
    participant System as システム

    UserA->>System: 社員名簿で相手のプロフィールを開き「メッセージを送る」をクリック
    System->>System: 既存のチャットルームを確認
    alt 過去にチャットしたことがある
        System-->>UserA: 既存のチャット画面を表示（過去の履歴付き）
    else 初めてのチャット
        System->>System: 新しいチャットルームを自動作成
        System-->>UserA: 新しいチャット画面を表示
    end
```

## 5. ナレッジベース（Wiki）記事作成フロー

社員がナレッジベースに新しい記事を作成する流れを示します。画像の添付にも対応しています。

```mermaid
sequenceDiagram
    autonumber
    actor User as 執筆者
    participant System as システム

    User->>System: 「新規作成」をクリック
    System-->>User: 記事作成画面を表示

    User->>System: タイトル・本文（Markdown形式）を入力

    opt 画像を添付する場合
        User->>System: 「画像を追加」ボタンをクリック
        User->>System: デバイスから画像ファイルを選択
        System->>System: 画像をアップロード
        System-->>User: 「アップロード中...」→「アップロード成功」通知を表示
        System-->>User: 本文に画像を自動挿入
    end

    User->>System: 「保存」をクリック
    System->>System: 記事を保存
    System-->>User: 記事ページを表示（保存完了）
```

---

## 6. ナレッジベース（Wiki）記事削除フロー

記事を削除する際、添付画像も自動的にクリーンアップされる流れを示します。

```mermaid
sequenceDiagram
    autonumber
    actor User as 利用者
    participant System as システム

    User->>System: 記事ページで「削除」ボタンをクリック
    System-->>User: 確認ダイアログを表示（「本当に削除しますか？」）
    User->>System: 「はい」をクリック
    System->>System: 記事内の添付画像を自動削除
    System->>System: 記事データを削除
    System-->>User: 「削除しました」通知を表示し、一覧ページへ遷移
```

## 7. カレンダーイベント作成フロー

カレンダーにイベントを登録する流れを示します。公開範囲（スコープ）の設定により、表示される対象が異なります。

```mermaid
sequenceDiagram
    autonumber
    actor User as 利用者
    participant System as システム

    User->>System: カレンダー画面で日付を選択し「イベント作成」をクリック
    System-->>User: イベント作成フォームを表示

    User->>System: イベント情報を入力（タイトル、日時、内容）
    User->>System: 公開範囲を選択
    Note over User, System: 公開範囲の選択肢：<br/>・全社（全社員に表示）<br/>・グループ（所属グループのメンバーのみ表示）<br/>・個人（自分のみ表示）

    User->>System: 「保存」をクリック
    System->>System: イベントを保存
    System-->>User: カレンダーにイベントを表示
```

---

## 8. カレンダー表示と公開範囲フィルタリングフロー

カレンダーを開いた際に、公開範囲に応じて表示されるイベントが自動的にフィルタリングされる仕組みを示します。

```mermaid
sequenceDiagram
    autonumber
    actor User as 利用者
    participant System as システム

    User->>System: カレンダーページを開く
    System->>System: 登録済みイベントを取得

    Note over System: 公開範囲に基づく自動フィルタリング

    System->>System: 「全社」イベント → 全て表示
    System->>System: 「グループ」イベント → 利用者が所属するグループのみ表示
    System->>System: 「個人」イベント → 利用者本人が作成したもののみ表示

    System-->>User: フィルタリング済みのイベント一覧をカレンダーに表示
```

---

## 9. お知らせ作成・カレンダー連携フロー

管理者がお知らせを作成し、任意でカレンダーにも自動登録する流れを示します。

```mermaid
sequenceDiagram
    autonumber
    actor Admin as 管理者
    participant System as システム

    Admin->>System: お知らせ作成画面を開く
    Admin->>System: タイトル・本文・日時を入力
    Admin->>System: 「カレンダーにも登録する」オプションを選択（任意）
    Admin->>System: 「投稿」をクリック

    System->>System: お知らせを保存

    opt 「カレンダーにも登録する」が選択された場合
        System->>System: カレンダーにイベントを自動登録（お知らせと連動）
    end

    System-->>Admin: 「投稿しました」通知を表示
```

---

## 10. お知らせ削除時のカレンダー連動フロー

お知らせを削除すると、連携しているカレンダーイベントも自動的に削除される流れを示します。

```mermaid
sequenceDiagram
    autonumber
    actor Admin as 管理者
    participant System as システム

    Admin->>System: お知らせ一覧から対象のお知らせの「削除」をクリック
    System-->>Admin: 確認ダイアログを表示
    Admin->>System: 「はい」をクリック

    System->>System: お知らせデータを削除

    opt カレンダー連携がある場合
        System->>System: 連携しているカレンダーイベントも自動削除
    end

    System-->>Admin: 「削除しました」通知を表示し、一覧ページへ遷移
```
